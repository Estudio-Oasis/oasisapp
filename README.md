# Estudio Oasis

Sitio corporativo reutilizable construido con React, TypeScript, Vite y Tailwind CSS.

## Desarrollo local

```sh
bun install
bun run dev
```

## Producción

```sh
bun run build
bun run preview
```

El proyecto es exclusivamente frontend y no depende de una base de datos, autenticación, almacenamiento ni funciones de servidor. El formulario de contacto prepara un correo en la aplicación de email del visitante.
